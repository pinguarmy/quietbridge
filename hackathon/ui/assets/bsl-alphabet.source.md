# BSL alphabet illustration source

Original user-supplied `Sign-Language.png`, retained byte-for-byte as `bsl-alphabet.png` (744 by 1215 RGBA pixels).

SHA-256: `4f25735083efd6b2146ce96b61349d21c00e2858e94225987ddac6f4ab5b9404`.

The introduction draws per-letter regions from this original chart at display time using the crop map in `../hand-letters.json`. CSS inverts/grayscales the displayed line art for the navy theme; no edited bitmap asset is generated. It is a decorative BSL fingerspelling illustration, separate from the live prototype gesture recognizer and from the ASL MNIST experiment. The chart author and license were not supplied; this file records user-provided provenance and does not assign a license.
